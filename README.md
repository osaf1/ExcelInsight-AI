## Projectgegevens

### Naam van het project

**ExcelInsight AI – AI Excel Data Analyst**

### Beschrijving van het project

Voor dit project maak ik een applicatie waarmee gebruikers Excel-bestanden kunnen uploaden en automatisch kunnen laten analyseren.

De applicatie gebruikt **Python** en de **Pandas library** om gegevens uit Excel-bestanden te lezen, te verwerken en te analyseren. Daarnaast maak ik een **AI-agent** die de resultaten van de data-analyse kan gebruiken om vragen van de gebruiker te beantwoorden.

De gebruiker kan bijvoorbeeld vragen stellen zoals:

* Wat is de totale omzet?
* Welk product verkoopt het beste?
* Welke maand had de hoogste omzet?
* Waar zijn opvallende veranderingen in de data?
* Welke producten leveren de meeste winst op?
* Welke aanbeveling geeft de AI op basis van de gegevens?

Het doel is om een gebruiksvriendelijke applicatie te maken waarmee iemand zonder veel kennis van data toch snel inzicht kan krijgen in een Excel-bestand.

### Waarom wil ik dit project maken?

Ik wil dit project maken omdat ik meer wil leren over **Python, data-analyse en Artificial Intelligence**.

Ik wil leren hoe ik met Pandas grote hoeveelheden gegevens kan verwerken en hoe ik deze gegevens kan gebruiken binnen een praktische applicatie.

Daarnaast wil ik leren hoe een **AI-agent** kan samenwerken met Python-functies. De AI-agent moet niet alleen tekst geven, maar ook daadwerkelijk tools kunnen gebruiken om gegevens te analyseren.

Met dit project wil ik een praktisch project maken dat ik later ook kan gebruiken voor mijn **portfolio**.

## AI-agent

Een belangrijk onderdeel van het project is de AI-agent.

De AI-agent krijgt verschillende Python-tools waarmee hij data kan analyseren. De agent kan bepalen welke tool nodig is om een vraag van de gebruiker te beantwoorden.

Voorbeelden van tools zijn:

* `calculate_total_sales()`
* `calculate_profit()`
* `find_best_product()`
* `find_worst_product()`
* `compare_months()`
* `find_anomalies()`
* `create_report()`

Bijvoorbeeld:

**Vraag van de gebruiker:**

> Waarom was de omzet deze maand lager?

De AI-agent kan vervolgens de beschikbare data analyseren, verschillende maanden vergelijken en uitleggen waardoor het verschil waarschijnlijk is ontstaan.
